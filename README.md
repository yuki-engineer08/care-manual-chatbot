# care-manual-chatbot

介護現場における事故報告書作成の属人化を解消するため、Claude APIを活用して報告書の自動生成・要因分析を支援するチャットボットです。

## ① プロジェクト概要

介護現場では、事故発生時の報告書作成が記録者の経験や文章力に依存しがちで、内容の質や再発防止策の検討に差が生まれやすいという課題があります。本プロジェクトは、Anthropic Claude APIを用いて、誰でも一定の質で事故報告書を作成できるチャットボットを構築し、属人化の解消を目指すものです。

## ② 背景・課題

介護現場での実務経験から、以下の課題を感じたことが開発の出発点です。

- 事故報告書の書き方が職員によってばらつき、原因分析が浅くなりがちである
- 多忙な現場では、報告書作成に十分な時間を割けないことが多い
- 再発防止策が「気をつける」といった抽象的な内容に留まり、具体的な対策に結びつきにくい

これらを解消するために、報告内容を入力するだけで構造化された報告書と要因分析が得られる仕組みを目指しました。

## ③ 主な機能

- **事故報告書の自動生成**: 事故発見時・発見後の状況をもとに、報告書として整った文章を自動生成
- **4要因分析**: 「ご利用者様要因」「介護側要因」「環境要因」「再発防止策」の4つの観点で要因を整理し、それぞれ100字以内で出力
- **再発防止策の具体化**: 生活リズムなど、対象者に寄り添った実行可能な再発防止案を提示
- **Web UI / CLI 両対応**: ブラウザのチャット画面、またはターミナルからの対話で利用可能

## ④ 技術スタック

- **バックエンド**: Python, FastAPI
- **AIモデル**: Anthropic Claude API（`claude-haiku-4-5`）
- **インフラ（AWS）**: Lambda, API Gateway, S3, CloudFront
- **IaC**: AWS SAM（AWS::Serverless-2016-10-31）
- **フロントエンド**: 素のHTML/CSS/JavaScript（ビルド不要）

## ⑥ セットアップ手順

### ローカル開発

```bash
pip install -r requirements.txt
```

`.env` に Anthropic APIキーを設定:

```
ANTHROPIC_API_KEY=your_api_key_here
```

CLIで起動:

```bash
python src/chat.py
```

Webで起動（http://127.0.0.1:8000 でチャットUIとAPIを提供）:

```bash
cd src
uvicorn api:app --reload
```

### AWSへのデプロイ（SAM）

```bash
sam build
sam deploy --guided
```

デプロイ時に `AnthropicApiKey` パラメータの入力が必要です。デプロイ後、`FrontendBucketName` に静的ファイルをアップロードし、`CloudFrontDistributionId` でキャッシュ無効化を行ってください。

## ⑦ 今後の展望（Future Improvements）

- **Amazon Bedrockへの移行**: AWS環境内でのモデル運用に統合し、APIキー管理の簡素化とガバナンス強化を図る
- **Cognitoによる認証導入**: 施設職員単位でのアクセス制御・利用ログの管理を実現する
- **RAGによるマニュアル参照機能**: 施設独自の介護マニュアルや過去の事例を参照し、回答の精度と現場適合性を高める
- **ファイル添付（PDF/画像）対応**: 既存の手書き報告書や写真を取り込んで報告書作成を支援する
- **HL7 FHIR準拠の構造化データ対応**: 医療・介護記録システムとの相互運用性を見据えた構造化データ出力に対応する
