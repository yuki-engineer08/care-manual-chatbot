Claude Code よく使うコマンド一覧

スラッシュコマンド

コマンド説明
/helpClaude Code の使い方を表示する
/clear会話履歴をクリアする
/configテーマやモデルなどの設定を変更する
/loginアカウントにログインする
/logoutアカウントからログアウトする
/model使用するモデルを切り替える
/initCLAUDE.md（プロジェクト設定ファイル）を新規作成する
/reviewプルリクエストをレビューする
/code-review現在の差分をレビューする（低〜高精度モードあり）
/security-review未コミットの変更をセキュリティ観点でレビューする
/loop指定したコマンドを一定間隔で繰り返し実行する
/scheduleクラウド上で定期実行されるエージェントを設定する
/fast高速応答モード（Opus）を切り替える

ショートカット・操作

操作説明
!<command>シェルコマンドをそのセッション内で実行する
Ctrl+C現在の処理を中断する
Esc入力中の内容を取り消す／確認を閉じる
Shift+Tab権限モード（Plan/Auto など）を切り替える
